# OnIt

לו״ז שבועי אישי לאייפון: אפליקציית אינטרנט שמותקנת למסך הבית.

- כל המידע נשמר בטלפון בלבד, וגיבוי אוטומטי נשמר בחשבון הגוגל של המשתמשת (Apps Script).
- הריפו מכיל רק את קוד האפליקציה, בלי מידע אישי ובלי קוד חיבור.

**עדכון גרסה:** אחרי שינוי בקבצים, להעלות את המספר ב-`sw.js` (`onit-v1` → `onit-v2`) כדי שהטלפון יקלוט את הגרסה החדשה.
